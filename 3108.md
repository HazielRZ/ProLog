## Validación de Jerarquía de Paréntesis

### Descripción

Programa en JavaScript que evalúa si una expresión con paréntesis está correctamente balanceada. Utiliza una **pila (stack)** como estructura de datos principal para verificar que cada paréntesis de apertura `(` tenga su correspondiente paréntesis de cierre `)`.

### Estructura de datos: Pila (Stack)

La pila es una estructura de datos **LIFO** (Last In, First Out — último en entrar, primero en salir). En JavaScript se implementa con un arreglo (`[]`) usando los métodos:

- `push()` — agrega un elemento al tope de la pila.
- `pop()` — remueve y retorna el elemento del tope.
- `length` — indica cuántos elementos hay en la pila (si es `0`, la pila está vacía).

### Algoritmo

1. Se recorre cada carácter de la expresión.
2. Si se encuentra un `(`, se agrega a la pila.
3. Si se encuentra un `)`:
   - Si la pila está **vacía**, se retorna `false` (hay un cierre sin apertura).
   - Si la pila **no está vacía**, se remueve el tope (se empareja con el `(` correspondiente).
4. Al terminar el recorrido, si la pila está **vacía**, la expresión es **correcta**; de lo contrario, es **incorrecta** (quedan paréntesis de apertura sin cerrar).

### Código

```javascript
/**
 * Valida que los paréntesis de una expresión estén correctamente balanceados
 * utilizando una estructura de pila (stack).
 *
 * @param {string} expresion - La cadena que contiene los paréntesis a evaluar.
 * @returns {boolean} true si los paréntesis están balanceados, false en caso contrario.
 */
function validacion(expresion) {
    const pila = [];

    for (let i = 0; i < expresion.length; i++) {
        if (expresion[i] === '(') {
            pila.push(expresion[i]);
        }

        if (expresion[i] === ')') {
            if (pila.length === 0) {
                return false; // paréntesis de cierre sin paréntesis de apertura
            }
            pila.pop();
        }
    }

    // Si la pila está vacía, la expresión es correcta
    const valida = pila.length === 0;
    if (valida) {
        return true; // correcta
    } else {
        return false; // error: quedan paréntesis de apertura sin cerrar
    }
}

// --- Programa principal ---

const expresiones = [
    "((()()",     // incorrecta — falta un cierre
    "(())()",     // correcta
    ")()",        // incorrecta — cierre antes de apertura
    "()",         // correcta
    "((()))",     // correcta
    "(()",        // incorrecta
    "",           // correcta — cadena vacía
];

expresiones.forEach(expresion => {
    const resultado = validacion(expresion);
    if (resultado === true) {
        console.log(`La expresión: "${expresion}" es correcta`);
    } else {
        console.log(`La expresión: "${expresion}" es incorrecta`);
    }
});
```

### Ejemplo de ejecución

```
La expresión: "((()()" es incorrecta
La expresión: "(())()" es correcta
La expresión: ")()" es incorrecta
La expresión: "()" es correcta
La expresión: "((()))" es correcta
La expresión: "((" es incorrecta
La expresión: "" es correcta
```

### Complejidad

| Aspecto   | Complejidad |
|-----------|-------------|
| Tiempo    | O(n)        |
| Espacio   | O(n)        |

Donde **n** es la longitud de la expresión. En el peor caso (todos son `(`), la pila almacena todos los caracteres.
