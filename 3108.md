## Validación de Jerarquía de Paréntesis

### Descripción

Programa en JavaScript que evalúa si una expresión con paréntesis está correctamente balanceada utilizando una **pila (stack)** para verificar que cada paréntesis de apertura `(` tenga su correspondiente paréntesis de cierre `)`.

### Estructura de datos: Pila (Stack)

La pila es una estructura de datos **LIFO** (Last In, First Out). En JavaScript se implementa con un arreglo (`[]`) usando:

- `push()` — agrega un elemento al tope de la pila.
- `pop()` — remueve y retorna el elemento del tope.
- `length` — indica cuántos elementos hay en la pila (`0` si está vacía).

### Algoritmo

1. Se recorre cada carácter de la expresión.
2. Si se encuentra un `(`, se agrega a la pila.
3. Si se encuentra un `)`:
   - Si la pila está **vacía**, se retorna `false` (cierre sin apertura).
   - Si la pila **no está vacía**, se remueve el tope.
4. Al terminar el recorrido, retorna `pila.length === 0`.

### Código ([`3108.js`](3108.js))

```javascript
function validacion(expresion) {
    const pila = [];

    for (let i = 0; i < expresion.length; i++) {
        if (expresion[i] === '(') {
            pila.push(expresion[i]);
        } else if (expresion[i] === ')') {
            if (pila.length === 0) {
                return false;
            }
            pila.pop();
        }
    }

    return pila.length === 0;
}

const expresiones = [
    "((()()",
    "(())()",
    ")()",
    "()",
    "((()))",
    "(()",
    "",
];

expresiones.forEach(expresion => {
    const estado = validacion(expresion) ? "correcta" : "incorrecta";
    console.log(`La expresión: "${expresion}" es ${estado}`);
});
```

### Ejemplo de ejecución

```text
La expresión: "((()()" es incorrecta
La expresión: "(())()" es correcta
La expresión: ")()" es incorrecta
La expresión: "()" es correcta
La expresión: "((()))" es correcta
La expresión: "(()" es incorrecta
La expresión: "" es correcta
```

### Complejidad

| Aspecto   | Complejidad |
|-----------|-------------|
| Tiempo    | $O(n)$      |
| Espacio   | $O(n)$      |

Donde $n$ es la longitud de la expresión.
